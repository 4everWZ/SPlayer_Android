# Android Native V2 集成验证

## 验收原则

- 当前交付门槛以 **模拟器手机竖屏 smoke test** 为主
- 真机功耗和热量结论不能用模拟器替代
- 未人工完成的项必须标记为“待人工验证”

## 构建与安装

- 单测：`android-native\gradlew.bat testDebugUnitTest`
- 构建：`android-native\gradlew.bat assembleDebug`
- 安装：`adb install -r android-native/app/build/outputs/apk/debug/app-debug.apk`

## Smoke Cases

### NAV-001

- 目标：底部导航只保留 `推荐 / 发现 / 我的`
- 通过标准：
  - 不出现 `播客`
  - 不出现“占位但不可点”的第四栏
- 当前状态：已通过模拟器截图回归

### DRAWER-001

- 目标：首页左上角抽屉只显示听歌相关入口
- 通过标准：
  - 仅保留账号头部、喜欢的音乐、最近播放、收藏歌单、设置
  - 不出现 VIP、消息、云贝、装扮、商城、票务、云推歌
- 当前状态：已通过模拟器截图回归

### HOME-RECOMMEND-001

- 目标：推荐页完成三段式首页结构
- 通过标准：
  - 顶部大搜索框可见
  - 频道切换条可见
  - 大卡推荐位可见
  - “猜你喜欢的好歌”短列表可见
  - 推荐歌单区可见
  - 不混入非音乐入口
- 当前状态：已通过模拟器截图回归

### DISCOVERY-MUSIC-001

- 目标：发现页只保留音乐浏览内容
- 通过标准：
  - 展示分类入口、歌单、榜单、新歌、新专辑、热门歌手
  - 不出现播客、听书、免费听
- 当前状态：代码已落地，待手工完整回归

### MY-MUSIC-001

- 目标：“我的”页只保留音乐资产结构
- 通过标准：
  - 展示头图和资产面板
  - 头图背景直接使用头像 URL；圆形头像仍正常显示
  - 头图图片缓存只按实际图片 URL 失效，不因普通页面刷新重复加载
  - 标签固定为 `近期 / 创建 / 收藏 / 专辑`
  - `近期` 固定按 `专辑 -> 歌单 -> 听歌排行` 三段收口
  - 喜欢的音乐置顶
  - 不出现播客、笔记、社交导流、非听歌服务卡
- 当前状态：按用户最终确认，头图背景直接使用头像 URL；资料背景字段仍保留但不驱动头图

### UNLOCK-SETTINGS-001

- 目标：设置页可切换 Android unlock 服务器模式
- 通过标准：
  - 默认模式为原生本地
  - 原生本地模式不启动桌面端 Node/Electron 本地 unlock 服务
  - 原生本地模式只把 `native-netease` 加入解锁候选
  - 外部服务器模式只请求 `API_ROOT/unblock/*` 候选
  - 播放失败源记忆仍能过滤当前模式下的候选
- 当前状态：代码和单测已覆盖默认值、候选切换和网易云直连请求，待真机播放样本回归

### MINIPLAYER-001

  - 曲名区域进入播放详情
  - 播放键和队列键独立命中
- 当前状态：代码已落地，待继续手工点击回归

### SEARCH-IME-001

- 目标：搜索页在 IME 弹起时不出现白块和错位
- 通过标准：

  - 热搜和结果列表正常显示
  - 不出现白块、空白页、错位
- 当前状态：待专项回归

### AUTH-QR-001

- 目标：二维码可见且登录后状态刷新
- 通过标准：
  - 二维码渲染成功
  - 扫码确认后设置页和首页同步刷新昵称
  - 不能只显示“登录成功”文案而仍然维持未登录
- 当前状态：代码已落地，待人工扫码回归

### PLAYER-CORE-001

- 目标：播放主链不回退
- 通过标准：
  - 播放详情无左右滑页
  - 点击封面进入歌词
  - 评论和队列都走底部抽屉
  - 缓冲阶段系统进度冻结
  - 中途卡流后继续走恢复链
- 当前状态：基础链路已保留，待扩大样本回归

### PLAYER-COVER-001

- 目标：播放详情封面态不再漂移
- 通过标准：
  - 手机竖屏下不出现中段大面积空白
  - 黑胶主视觉相对旧版继续下压，不能贴着标题区悬空
  - 黑胶与唱臂保持同一主视觉构图
  - 播放中黑胶恢复旋转，暂停或缓冲时不继续空转
  - 歌名、评论入口、进度条和主控形成连续纵向节奏
  - 控制区贴近底部安全区，不因封面态被顶出
- 当前状态：已完成基础响应式重排，待继续做多机型 smoke
- 当前补充记录：模拟器已回归封面态黑胶放大、唱臂回到黑胶构图内、歌名和评论入口不再被中段空白拉散

### PLAYER-LYRIC-002

- 目标：歌词页手动滚动与跳时交互对齐
- 通过标准：
  - 点击封面进入歌词页
  - 自动跟随态点击任意歌词或空白直接回封面
  - 手动滚动后出现中部预览锚点
  - 预览锚点显示时间戳和跳转按钮
  - 预览锚点独立悬浮在视区中部，不能把当前歌词行拉偏
  - 只有点击预览锚点才 seek
  - 预览态点击其他歌词区域或空白仍回封面
- 当前状态：已通过模拟器回归
- 当前补充记录：模拟器已回归“手动滚动出现中部锚点”“锚点不再把当前歌词行拉偏”和“点击空白返回封面”

### PLAYER-LYRIC-ALIGN-001

- 目标：歌词首句和末句都能落到同一视觉中线
- 通过标准：
  - 第一行自动跟随时与中间行共享同一视觉中线
  - 最后一行自动跟随时也共享同一视觉中线
  - 歌词正文保持独立居中内容块，左右留白对称，不出现整体偏左
  - 不因为固定 padding 在首尾出现上浮或下沉
- 当前状态：算法与单测已落地，歌词头尾 provider / credit 行已在数据层剥离，待继续扩大歌曲样本回归

### PLAYER-LYRIC-WORD-003

- 目标：存在字级时间时按字推进高亮
- 通过标准：
  - `yrc / qrc / TTML` 任一命中字级时间后，当前行不再整行一起变亮
  - 网易云 `yrc` 的字时间按绝对毫秒推进，不能再出现整行延后一拍才开始高亮
  - 已播放过的字保持高亮
  - 当前推进中的字按时间逐步变亮
  - 单词内部也继续按字推进，不允许整词一起跳亮
  - 没有字级时间时才允许退回逐句高亮，且不能继续维持真逐字刷新频率
- 当前状态：基础链路已落地，待继续做多歌词源样本回归
- 当前补充记录：`lyric/new` 命中网易云 `yrc` 时继续走真逐字；没有字级时间的普通 LRC 已明确退回逐句级高亮，不再维持逐字刷新节拍

### PLAYLIST-001

- 目标：喜欢的音乐与普通歌单详情保持懒加载分页模型
- 通过标准：
  - “我喜欢的音乐”可正常打开
  - 我的页进入后允许后台单次预热喜欢歌单预览
  - 进入歌单详情时优先显示预览数据
  - 预热与正式打开不会并发重复拉同一歌单预览和首屏分页
  - 首屏仅拉第一页
  - 近底自动续页
  - 播放全部前补齐剩余分页
  - 异常响应不直接显示底层拼接报文
- 当前状态：已通过模拟器打开与分页基础回归

### COMMENTS-001

- 目标：评论抽屉可打开、分页、保留底部安全区
- 通过标准：
  - 首次进入播放详情时允许后台单次预热评论
  - 打开评论抽屉后优先显示缓存，再补齐热门和最新评论
  - 预热与正式打开不会并发重复拉同一首歌的热门和最新评论首屏
  - 评论抽屉关闭后不再保留评论相关高频刷新
- 当前状态：代码已落地，待继续做弱网和多歌曲样本回归

### POWER-EMU-001

- 目标：明显高频空转不再常驻
- 通过标准：
  - 进度刷新只在播放且被观察时运行
  - buffering watchdog 只在真实恢复窗口内运行，退出缓冲后立即停止
  - 二维码轮询只在二维码可见时运行
  - 评论和歌词区域不制造额外常驻轮询
- 当前状态：已完成代码级收口，模拟器 `cpuinfo` 快照中进程约 `0.4%`，`gfxinfo` GPU 占用约 `2.25 MB`，真机结论仍待专项采集
- 当前补充记录：播放详情当前分成三档刷新节拍，封面态约 `900ms`，普通歌词约 `650ms`，只有真逐字歌词才升到约 `120ms`

### CLEANUP-001

- 目标：移出主线的入口在 UI、文档和 smoke 中都消失
- 通过标准：
  - 主导航无播客
  - 抽屉无非听歌入口
  - 文档与矩阵无旧主线路径表述
- 当前状态：已完成
