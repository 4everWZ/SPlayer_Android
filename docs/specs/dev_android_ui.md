# Android Native V2 UI 文档

## 设计目标

- 对齐网易云音乐手机竖屏听歌主路径的信息架构和交互节奏
- 保持 `SPlayer` 品牌，不复制网易云品牌资产
- 只保留听歌主线，不承接非音乐内容和商业化入口

## 全局规则

- 底部主导航固定为：`推荐 / 发现 / 我的`
- 设置不再作为底部一级 tab
- 首页左上角抽屉是唯一设置收口入口
- 抽屉只保留听歌相关入口
- 小播放条常驻在底部导航上方
- 小播放条除 `播放/暂停` 与 `队列按钮` 外，整条进入播放详情
- 播放详情固定单轴交互，不允许左右滑页
- 评论和队列统一使用底部抽屉
- 顶部状态栏、底部导航栏和底部抽屉都必须显式消费 safe area
- IME 弹起后只允许内容区重排，不允许白块、空白页和错位

## 推荐页

### 布局结构

- 顶部左侧抽屉按钮
- 中部大搜索框
- 右侧搜索相关动作位
- 音乐频道切换条
- 大卡推荐位
- “猜你喜欢的好歌”短列表
- 推荐歌单区
- 新碟 / 热门专辑区
- 排行榜区

### 频道固定项

- `推荐`
- `新歌`
- `歌单`
- `专辑`
- `排行`

### 交互规则

- 推荐卡片采用大图主卡，不再退化为通用小卡横滑
- 短列表必须支持直接播放
- 所有分区都只能展示音乐内容
- 不得出现听书、免费听、票务、广告位、会员专区等入口

## 发现页

### 布局结构

- 顶部标题与搜索入口
- 分类入口
- 分类歌单区
- 榜单聚合区
- 新歌 / 新碟区
- 热门歌手区

### 交互规则

- 发现页承担“音乐浏览页”角色，不再承接播客、听书、免费听
- 分类入口用于快速找歌，不展示死按钮
- 新歌直接播放
- 新专辑进入专辑详情，不允许再落回歌单详情

## 我的页

### 布局结构

- 上半部个人头图区
- 头像
- 昵称
- 个性签名
- 听歌资产统计
- 下半部音乐资产面板
- 资产标签栏
- 喜欢的音乐固定置顶卡

### 资产标签

- `近期`
- `创建`
- `收藏`
- `专辑`

### 交互规则

- “我的”页只保留音乐资产，不再展示播客、笔记、消息、云贝、装扮、商城、票务、VIP 卡等内容
- 喜欢的音乐保留为首位大项
- 设置不出现在“我的”页主内容中

## 抽屉

### 布局结构

- 账号头部
- 喜欢的音乐
- 最近播放
- 收藏歌单
- 设置

### 交互规则

- 不再保留“更多”二级聚合
- 不展示非听歌菜单项

## 搜索页

### 布局结构

- 顶部搜索框
- 热搜区
- 搜索结果区

### 交互规则

- 原生 IME 驱动
- 支持热搜和外部关键词直达
- 结果点击直接进播放主线或详情主线
- 不允许出现白块、空白页、整屏错位

## 播放详情页

### 布局结构

- 顶部唯一标题区
- 封面主区
- 黑胶主视觉容器
- 进度区
- 主控制区
- 评论 / 队列次级入口

### 交互规则

- 顶部只保留一个标题区
- 封面态必须按可用视区做响应式分配，不允许再写死固定 `430.dp` 封面区或固定 `360.dp` 黑胶尺寸
- 黑胶尺寸必须按屏宽和可用高度联合上探，不能再被窄化的固定上限压小
- 黑胶主视觉要明显下压，标题区下方必须先留出呼吸，再进入黑胶主视觉，不能让唱片顶在页面上半部
- 黑胶、唱臂、歌名、评论入口、进度区要形成连续纵向节奏，不允许出现中段大面积空白
- 唱臂必须锚定在黑胶主视觉容器内部，不允许脱离黑胶构图飘到页面右上角
- 不新增 MV、小灯泡、AI 调音、样式商城等入口
- 点击封面进入歌词页
- 缓冲时系统进度冻结，UI 要给出反馈

## 歌词页

### 布局结构

- 复用播放页顶部标题区
- 中部滚动歌词区
- 底部复用播放控制区

### 交互规则

- 点击封面进入歌词
- 点击顶部返回封面
- 首句、末句和中间行必须共享同一视觉中线，不允许因为固定 padding 在首尾漂移
- 自动跟随态下，点击任意歌词行或空白区域都返回封面
- 手动滚动歌词后进入预览态
- 预览态只在视区中部保留一个跳时锚点，展示目标时间戳和跳转按钮
- 只有点击当前中部预览锚点才执行 seek
- 预览态点击其他歌词区域或空白区域仍然返回封面
- 存在字级时间数据时，当前行必须走逐字高亮而不是整行一起变亮，单词内部也要继续按字推进
- 默认不显示音译
- 翻译、音译、字号由设置控制
- provider / credit / Cloud Drive 这类头尾元信息不能进入主歌词视区
- 顶部不允许重复出现第二个歌曲头部

## 评论抽屉

- 展示评论总数
- 展示热门评论
- 展示最新评论
- 支持分页加载
- 底部必须保留安全区
- 首次进入播放详情后允许后台单次预热评论首屏缓存
- 评论抽屉未真正打开前，不允许为评论列表维持持续轮询或重复刷新

## 播放队列抽屉

- 展示当前播放数量
- 点击队列项直接切歌
- 底部必须保留安全区

## 设置页

### 分组

- 账号
- 播放
- 歌词
- 网络
- 外观
- 缓存 / 本地资源
- 关于 / 诊断

### 规则

- 默认暗色
- 提供明暗主题切换
- 不展示会员中心、充值、广告偏好等营销型分组

## 性能与生命周期约束

- 进度刷新循环只允许在播放器被观察、正在播放且未缓冲时运行
- 卡流 watchdog 只允许在存在当前歌曲、处于缓冲且 `playWhenReady=true` 的恢复窗口内运行，退出缓冲后立即停止
- 二维码轮询只允许在二维码可见且登录流程仍活跃时运行
- 评论和歌词刷新只能由显式交互触发，不允许脱离页面生命周期空转
- “我喜欢的音乐”和普通歌单允许做单次预热：
  - 我的页拿到喜欢歌单后可先补歌单预览
  - 预览不足一屏时再后台补齐首屏歌曲
  - 该预热只允许随页面生命周期触发一次，不能转成常驻后台刷新
